# NovaPath Website Redesign — Full Replit Build Prompt

## Overview

Rebuild explorenovapath.com as a consulting landing page for NovaPath, an AI consulting practice for K-12 school districts. The site should position NovaPath as a premium, practitioner-led consulting firm — not a SaaS product, not a PD workshop vendor. The founder, Dan Whitlock, is the face of the brand. People hire Dan. NovaPath is the entity.

This is a single-page site. No routing needed. Clean, fast, conversion-focused. One goal: get a qualified superintendent or district leader to schedule a free consultation.

## Brand System (MUST MATCH EXACTLY)

These colors and fonts are shared across Dan's entire brand ecosystem (newsletter, LinkedIn, this site). Consistency is non-negotiable.

```css
:root {
  --bg-primary: #0F0A1A;        /* Deep purple-black — main background */
  --bg-card: #1A1425;           /* Slightly lighter — card/section backgrounds */
  --bg-elevated: #241E30;       /* Elevated surfaces, hover states on cards */
  --accent-primary: #7C5CFF;    /* Vibrant purple — CTAs, highlights, links */
  --accent-hover: #A78BFA;      /* Lighter purple — hover states, secondary accents */
  --accent-glow: rgba(124, 92, 255, 0.15); /* Subtle glow/gradient behind elements */
  --text-primary: #F5F3FF;      /* Near-white with slight purple tint — headlines */
  --text-body: #B4B0C4;         /* Muted purple-gray — body text */
  --text-dim: #6B6580;          /* Dimmed — labels, captions, meta text */
  --border: #2A2435;            /* Subtle borders between sections */
  --success: #4ADE80;           /* Green for checkmarks, positive indicators */
}
```

**Font:** Use `"DM Sans"` from Google Fonts for everything. Bold (700) for headlines, Medium (500) for subheads, Regular (400) for body. DM Sans is clean and modern without being generic. Import: `https://fonts.googleapis.com/css2?family=DM+Sans:ital,opsz,wght@0,9..40,400;0,9..40,500;0,9..40,700;1,9..40,400&display=swap`

**Design Aesthetic:** Dark, premium, confident. Think high-end SaaS crossed with editorial design. Generous whitespace. No clutter. No playful edtech vibes. No teal or green anywhere. This should feel like a site that a superintendent would take seriously — not a teacher's Pinterest board.

**Subtle texture/depth:** Use very faint radial gradients of `--accent-glow` behind key sections to create depth. A barely-visible noise texture overlay on the background adds premium feel. Subtle purple gradient lines or dividers between sections.

## Responsive Behavior

- **Desktop (1200px+):** Full two-column layouts, generous spacing
- **Tablet (768-1199px):** Reduce columns to single where needed, maintain readability
- **Mobile (< 768px):** Single column everything. Hero photo can be smaller or hidden (Dan appears in the bio section anyway). Form fields stack vertically. CTAs become full-width. Font sizes scale down proportionally.

## Performance & Technical Notes

- Single HTML page, no framework needed. Vanilla HTML/CSS/JS is fine. If you want to use a framework, keep it minimal.
- Lazy-load Dan's headshot photos
- Use CSS scroll-behavior: smooth for anchor links
- Add subtle fade-in animations on scroll (IntersectionObserver) for each section — nothing aggressive, just gentle opacity + translateY transitions as sections enter viewport
- Ensure the page scores 90+ on Lighthouse for performance
- Use semantic HTML (section, article, header, footer, nav)
- The sticky nav should have a z-index above everything
